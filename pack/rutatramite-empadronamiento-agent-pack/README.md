# RutaTrámite — Mega Pack Empadronamiento AMPLIADO

Pack para que un agente construya la mejor web SEO+GEO de empadronamiento en **todos los municipios de España con 10.000 habitantes o más**.

- **769 municipios** listados (población pública 1-ene-2025). Reconciliar con INE (~783).
- Textos largos: pilar 3.000+, escenarios 4.000+, ficha 1.200–1.800, legal 1.500+.
- Dominio canónico: rutatramite.es
- Empieza por AGENTS.md y 07_prompts/MASTER_AGENT.md
- Catálogo: data/CATALOGO_10K.md y data/municipios_10k.csv

Principio: el empadronamiento es municipal. La norma es estatal. Nunca inventes la sede.
