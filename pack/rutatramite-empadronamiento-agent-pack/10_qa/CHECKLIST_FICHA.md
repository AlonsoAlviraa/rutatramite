# Checklist por ficha published

- [ ] `ine_code` de 5 dígitos coincide con INE
- [ ] Nombre oficial correcto (incl. forma bilingüe si aplica)
- [ ] `sede_url` HTTP 200 y host municipal
- [ ] Canal coherente con la sede (no “online” si solo hay instancia genérica)
- [ ] Cita: URL real o `walk-in` o `unknown` (si unknown → noindex)
- [ ] Oficinas: dirección real o campo vacío
- [ ] Teléfono: real o omitido
- [ ] `tasa_alta = 0`
- [ ] `docs_extra` no contradice INE sin citar la sede
- [ ] Volante vs certificado no se mezclan
- [ ] `last_verified` ≤ 90 días (≤ 30 en top 20)
- [ ] `source_urls` ≥ 1
- [ ] Disclaimer visible
- [ ] Schema sin errores
- [ ] OG title corto
- [ ] No stuffing
